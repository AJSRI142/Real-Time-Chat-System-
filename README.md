# Multithreaded Chat System

A client-server chat system built in C++ using POSIX sockets and TCP.
The server uses multithreading to support 100+ connected clients and
provides reliable bidirectional communication between clients.

## Technologies
- C++
- POSIX sockets
- TCP
- Multithreading

## Features
- Supports 100+ concurrent clients
- Reliable TCP-based communication
- Handles unexpected client disconnections
- Cleans up socket and thread resources to keep the server running
